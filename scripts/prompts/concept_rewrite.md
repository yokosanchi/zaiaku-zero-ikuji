## リライトの指示

1. **トーン**：徹底的な共感と肯定へ。読者を責める・急かす気配を消す。免罪符を渡す語りに。
2. **禁止語を完全に除去**：「〜すべき」「〜してください」「〜しなきゃダメ」「がんばりましょう」。
3. **構成を基本形に整える**：共感の情景 → （出典があれば）📊引用ブロック → 罪悪感を外す考え方 → 現実的な工夫（箇条書き）→ `## まとめ`（3点前後）→ 肯定のひとこと。
4. **YMYL**：乳幼児の健康・安全の断定を消す。危険表現（1歳未満のはちみつ / うつ伏せ寝の推奨 / 自己判断の断薬・受診回避 / 発熱・けいれんの様子見断定 / 予防接種の忌避）が下書きに混じっていたら、その主張は削除し「かかりつけ医・自治体の相談窓口へ」に置き換える。
5. **ガバナンス方針（必須）**：
   - 罪悪感を減らす対象は「家事・作業の工程」だけ。子どもの安全・情緒的応答（愛情表現・声かけ）を減らすことは推奨しない。
   - 記事は「省力化で生まれた時間と心のゆとりを、子どもとの笑顔のやりとりに還元する」で締める。
   - 「育児は適当でいい」「放置しても育つ」等の乱暴な断定は使わない。手作りや特定の方針をがんばる親を下げる比較もしない。
   - レトルト・惣菜・市販品を勧めるときは、毎食完全依存を勧めず、栄養を補う簡単な工夫（汁物・果物を添える等）を併記。誤飲・喉詰め・アレルギーは公的ガイドラインベースの注意を添える。
   - スマホ・動画・TVを扱うときは「無制限の放置」ではなく時間のメリハリ（例：30分まで、夕飯準備中だけ）や作品の選定を提示し、見せたあとに短い双方向の会話（「どれが面白かった？」）を挟む案をセットにする。
   - 「親が別室で休む」「家事に没頭する」等は、誤飲・転落・浴室/ベランダ対策（ベビーゲート・モニター等）が済んでいる前提だと明記する。
   - 専門家（小児科医・栄養士等）の領域に踏み込む医療的判断や自己流の治療法は書かない。必ず「違和感があれば医療機関へ」を添える。
6. **見出しは `##` と `###` のみ**。`#` は使わない。末尾に「最後に、あなたへ」節は付けない（テンプレートが自動で付ける）。
7. 事実に自信が持てない部分は、断定をやめて「〜とされている / 〜という声もある」に弱める。
